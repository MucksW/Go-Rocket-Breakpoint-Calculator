# GO Rocket Breakpoint Calculator

A breakpoint calculator designed to determine the turns to victory in Team GO Rocket battles for Pokémon GO.

The tool can be accessed on [GO Rocket Breakpoint Calculator](https://mucksw.github.io/Go-Rocket-Breakpoint-Calculator/).

Special thanks to the community researchers and projects whose data and formulas made this tool possible:

- Pokémon GO Hub: For providing the CPM values.
- NFL Research Team: For providing the CPMR values.
